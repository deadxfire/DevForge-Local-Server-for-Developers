## Reporting a Vulnerability

Security and privacy are taken seriously in DevForge. If you discover a security vulnerability or security-related bug within DevForge, please report it privately to the developer.

- **Developer**: Arindam Makar
- **Email**: Contact via GitHub Profile or email associated with this repository.

Please include:
- A detailed description of the vulnerability.
- Steps or a minimal proof of concept to reproduce the issue.
- The version of DevForge and Windows OS on which the issue was observed.

You will receive an acknowledgment within 48 hours, and critical vulnerabilities will be addressed in an expedited update.
